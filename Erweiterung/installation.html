TreeHugger 1.5.1 installieren

Windows und Google Chrome

  1. Öffnen Sie 26_11_24_TreeHugger_1.5.1_Setup.exe und klicken Sie auf Installieren. Das Setup entpackt die Erweiterung samt Anleitung, Musterseiten und Fragen in Ihr Benutzerkonto.
  2. Öffnen Sie in Chrome chrome://extensions. Schalten Sie rechts oben den Entwicklermodus ein.
  3. Klicken Sie auf Entpackte Erweiterung laden. Fügen Sie den vom Setup angezeigten Ordnerpfad in das Ordnerfeld ein und bestätigen Sie. Vorgabe: %LOCALAPPDATA%\TreeHugger\Erweiterung.
  4. Öffnen Sie eine Webseite. Klicken Sie auf das Puzzleteil und dann auf TreeHugger. Über die Stecknadel können Sie das Baumsymbol anheften.

Für lokale HTML-Dateien aktivieren Sie in den Erweiterungsdetails Zugriff auf Datei-URLs zulassen.

Aktualisieren oder entfernen

Bei einer vom Setup installierten Version verwenden Sie erneut Installieren und anschließend Neu laden auf der Erweiterungskarte in Chrome. Schließen Sie alte TreeHugger-Tabs. Haben Sie bisher einen manuell entpackten Ordner verwendet, laden Sie einmal den neuen Setup-Ordner und entfernen Sie nach der Kontrolle den alten Eintrag. Eigene Klausurdaten können Sie vorher exportieren und danach importieren.

Zum Deinstallieren können Sie zuerst eine Sicherung Ihrer Klausurdaten exportieren. Entfernen Sie dann den Erweiterungseintrag in Chrome. Wählen Sie im Setup Entfernen, um die installierten Programmdateien zu löschen.

Klausurfragen bearbeiten

Öffnen Sie in TreeHugger oben Klausurfragen. Mit Klausursatz auswählen markieren Sie zwölf offene Aufgaben mit insgesamt 60 Punkten. Über die Kontrollkästchen können Sie Ihre Auswahl ändern. Klicken Sie auf Bearbeitung starten.

Ihre Antworten werden lokal gespeichert. Nach der Abgabe vergleichen Sie offene Antworten mit der Musterlösung und vergeben Teilpunkte. Bei eigenen Auswahlfragen berechnet TreeHugger die Punkte automatisch. Wer Zugriff auf die Fragenverwaltung hat, kann Musterlösungen einsehen. Für eine benotete Klausur können Lehrkräfte die Aufgaben ohne Lösungsschlüssel separat exportieren.

Unter Export und Datensicherung erzeugen Sie JSON-Dateien mit Aufgaben, Musterlösungen oder einer wieder importierbaren Gesamtsicherung. Gespeicherte Bearbeitungen behalten den Aufgabenstand vom Start der Bearbeitung.

Verschiebbare Bedienleiste

In Nur Baum beginnt die kompakte Leiste oben rechts. Ziehen Sie den Griff ⠿ an eine freie Stelle. Die Leiste wächst beim Baum-Zoom nicht mit. Ihre Position bleibt beim Wechsel zurück zur normalen Ansicht und erneut zu „Nur Baum“ in diesem Tab erhalten. Mit fokussiertem Griff können Sie auch die Pfeiltasten verwenden; Pos1 setzt die Position oben rechts zurück.
