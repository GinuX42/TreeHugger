Jedes Element ist ein Node. Sammlungen enthalten Verweise auf Elemente oder Knoten.
Merksatz: CSS beschreibt die Position („das zweite Kind“), JavaScript verwendet einen Index ([1]).

:nth-child(2) bedeutet „zweites Kindelement“. Die 2 ist eine Position, keine Anzahl von Kindern. CSS zählt hier ab 1; der JavaScript-Zugriff auf eine Sammlung beginnt bei 0.

Dasselbe direkte Kindelement auswählen
KindelementCSSJavaScript
Erstes:nth-child(1)elternElement.children[0]
Zweites:nth-child(2)elternElement.children[1]
Drittes:nth-child(3)elternElement.children[2]

* steht für jeden Elementtyp. *:nth-child(2) und :nth-child(2) bedeuten dasselbe. > führt jeweils zu einem direkten Kind; :root bezeichnet bei HTML das <html>-Element.

:nth-child() und children zählen nur Elemente. Textknoten, auch Leerraum, und Kommentare zählen dabei nicht mit. childNodes enthält zusätzlich diese Knoten und beginnt beim Indexzugriff ebenfalls bei [0]. Die DOM-Sammlungen children und childNodes sind keine Arrays.
